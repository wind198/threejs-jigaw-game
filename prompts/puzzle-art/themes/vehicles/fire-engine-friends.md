# Scene

A friendly red fire engine with a Dalmatian on the seat and a short ladder up.

# Composition

Engine center; ladder diagonal; dog mid-cab; hydrant lower-left; soft station building back.

# Color direction

Engine red, dog white-black, hydrant gold, building soft teal.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
