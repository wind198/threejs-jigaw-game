# Scene

A giant friendly cargo zeppelin above islands with smaller scout balloons and birds.

# Composition

Zeppelin dominant upper-mid; gondola details; scout balloons; island chain below; cloud layers.

# Color direction

Zeppelin ivory-teal, balloons coral, islands green-gold, sky layered blue.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
