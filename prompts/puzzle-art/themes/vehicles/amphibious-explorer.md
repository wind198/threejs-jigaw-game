# Scene

An amphibious explorer vehicle transitioning from beach to shallow reef with snorkel gear on top.

# Composition

Vehicle mid at waterline; beach left; reef right; gear details; seabirds; tide pools foreground.

# Color direction

Vehicle orange-teal, beach gold, reef turquoise, gear yellow accents.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
