# Scene

A cosmic lighthouse beaming rhythmic light pulses across asteroid islands.

# Composition

Lighthouse tower center asteroid; beam diagonal landmark; asteroid islands left and right; pulse rings.

# Color direction

Beam gold-white, tower teal, asteroids lavender-grey, space violet-blue.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
