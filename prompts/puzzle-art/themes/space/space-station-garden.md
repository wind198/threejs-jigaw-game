# Scene

A modular space station with greenhouse windows full of plants orbiting Earth.

# Composition

Station modules as geometric landmarks; greenhouse glowing green; Earth below curve; solar arrays.

# Color direction

Station white-teal, plants vivid green, Earth blue, arrays gold.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
