# Scene

Baby stars glowing inside a colorful nebula cradle with dust lanes.

# Composition

Nebula cloud filling frame with clear color regions; three bright baby stars; dust lane diagonal.

# Color direction

Nebula magenta, teal and gold regions, star white-gold cores, dust cocoa edges.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
