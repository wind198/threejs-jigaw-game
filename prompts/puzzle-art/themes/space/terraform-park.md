# Scene

Workers and robots planting forests on a half-green, half-red planet surface with weather machines.

# Composition

Planet surface split left green / right rust as clear regions; robots mid; weather machine towers; clouds forming; path network.

# Color direction

New forest emerald, rust soil, machine teal-gold, sky transitioning blue.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
