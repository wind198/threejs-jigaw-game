# Scene

Floating crystal books and star maps around a gentle owl librarian in space (no readable text).

# Composition

Owl center; crystal book shapes (blank covers) orbiting; constellation lines soft; planet shelf lower.

# Color direction

Owl amber, crystals cyan-violet, space indigo, planet coral accent.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
