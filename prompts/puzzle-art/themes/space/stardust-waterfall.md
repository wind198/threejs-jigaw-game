# Scene

A waterfall of glowing stardust pouring from a nebula cliff into a starry pool.

# Composition

Nebula cliff upper; stardust fall vertical center; pool lower with ripples; crystal trees sides.

# Color direction

Stardust cyan-gold, nebula magenta, pool deep sapphire, crystal trees mint.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
