# Scene

Lanterns and tiny ships celebrating inside a glittering comet tail corridor.

# Composition

Comet nucleus upper-left; tail corridor diagonal; lantern clusters; ships mid; ice crystals as texture landmarks.

# Color direction

Tail cyan-gold glitter, lantern warm amber, ships coral, ice blue.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
