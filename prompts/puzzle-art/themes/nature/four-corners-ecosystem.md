# Scene

One continuous landscape transitioning across forest, meadow, river and rocky shore with many landmarks.

# Composition

Forest canopy upper-left; meadow flowers upper-right; river diagonal; rocky shore lower; birds and stones as secondary landmarks in each quadrant.

# Color direction

Distinct greens, flower magenta, river turquoise, rock ochre — each region readable when cut into pieces.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
