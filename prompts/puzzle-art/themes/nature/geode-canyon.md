# Scene

A canyon wall sparkling with geode crystals, layered rock strata and a thin waterfall.

# Composition

Strata bands horizontal landmarks; geode clusters left and right; waterfall thin vertical; canyon floor path lower.

# Color direction

Crystal violet and cyan, strata terracotta-to-slate, waterfall white-blue.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
