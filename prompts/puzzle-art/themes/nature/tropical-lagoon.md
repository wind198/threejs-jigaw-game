# Scene

A turquoise lagoon with palm trees, white sand and colorful tropical flowers.

# Composition

Lagoon curve mid; palms left cluster; flower bushes right; sand crescent foreground.

# Color direction

Lagoon turquoise, palm emerald, flower coral and yellow, sand warm ivory (not cream-dominant).

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
