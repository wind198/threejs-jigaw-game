# Scene

A gentle aerial view of a ring-shaped coral atoll with teal lagoons and wave textures.

# Composition

Atoll ring as primary shape; lagoon center; outer ocean gradients; small island vegetation patches; wave foam arcs.

# Color direction

Lagoon turquoise bands, coral sand ivory-gold, deep ocean sapphire, green islet dots.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
