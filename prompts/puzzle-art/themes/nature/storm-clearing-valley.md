# Scene

Sunbeams breaking through storm clouds over a lush valley with a winding river.

# Composition

Cloud break upper-center with sunbeams; valley floor mid; river S-path; cliff left; orchards right.

# Color direction

Storm purple-grey clouds, sunbeam gold, valley green, river mirror blue.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
