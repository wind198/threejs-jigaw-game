# Scene

Towering redwoods with sun shafts, ferns, a creek and nesting birds in the canopy.

# Composition

Trunk columns as vertical landmarks; creek S-curve lower; fern carpets; birds mid-canopy; light shafts from upper-left.

# Color direction

Redwood russet bark, fern emerald, creek teal, golden sun shafts.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
