# Scene

A gentle bioluminescent forest path with glowing mushrooms, fireflies and mossy ruins.

# Composition

Path center; glowing mushrooms clusters in each corner; ruin arch mid-right; firefly dots upper; friendly soft light only.

# Color direction

Glow cyan and soft gold, moss jade, ruin lavender-stone, night indigo (cozy not scary).

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
