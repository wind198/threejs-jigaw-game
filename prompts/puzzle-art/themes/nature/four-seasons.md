# Scene

A magical single garden path gently transitioning from spring blossoms through summer foliage, autumn leaves and snowy winter.

# Composition

A winding path connects four recognizable seasonal zones in the same coherent landscape; central tree branches bridge areas.

# Color direction

Distinct pink, verdant green, amber and cool blue accents. Snow remains legible against contrasting dark teal trees.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers.
