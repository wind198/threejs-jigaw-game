# Scene

A friendly rounded volcano island with lush greenery and a blue ocean ring.

# Composition

Volcano cone center; green slopes; ocean surrounding as clear ring; small clouds; rocky shore foreground.

# Color direction

Ocean sapphire, slope jade, volcano soft charcoal tip, cloud lavender-white.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
