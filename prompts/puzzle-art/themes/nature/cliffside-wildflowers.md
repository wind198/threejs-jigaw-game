# Scene

Colorful wildflowers clinging to a seaside cliff above turquoise waves.

# Composition

Cliff diagonal from upper-left to lower-right; flower clusters as landmarks; ocean lower-right; sky upper.

# Color direction

Flower coral and violet, cliff warm sandstone, ocean turquoise, sky blue.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
