# Scene

A koala hugging a eucalyptus trunk with dangling leaves and a second koala peeking lower down.

# Composition

Main koala mid-trunk center; trunk as strong vertical; second koala lower-left; leaf clusters in all corners; soft blue distance.

# Color direction

Grey koala with warm brown nose, silvery eucalyptus leaves, bark umber, sky periwinkle.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
