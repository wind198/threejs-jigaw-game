# Scene

A rocky tide pool crowded with starfish, crabs, anemones, shells and a curious otter peeking in.

# Composition

Otter upper-left peeking; tide pool basin center; starfish and crab as distinct landmarks; rock texture rings; ocean spray upper-right.

# Color direction

Otter chocolate brown, starfish coral, anemone purple, pool turquoise, rock slate.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
