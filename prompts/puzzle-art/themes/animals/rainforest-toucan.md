# Scene

A toucan on a thick branch surrounded by tropical leaves, orchids and a waterfall glimpse.

# Composition

Toucan upper-center; oversized leaves framing corners; waterfall vertical strip right; orchid cluster lower-left.

# Color direction

Black-and-gold toucan, electric teal leaves, magenta orchids, cool waterfall blues.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
