# Scene

A busy beaver carrying a stick near a wooden dam with river water and reeds.

# Composition

Beaver mid-right; dam structure spanning middle as a horizontal landmark; river flowing left; reed clumps foreground.

# Color direction

Chestnut beaver, turquoise river, honey wood dam, lime reeds.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
