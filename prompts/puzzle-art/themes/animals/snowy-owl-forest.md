# Scene

A snowy owl launching from a pine forest with rabbits below, frost crystals and soft snowfall.

# Composition

Owl mid-flight center; pine trunks as vertical lattice; rabbits lower-left and right; frost sparkles; clearing path leading inward.

# Color direction

Owl white with charcoal markings, pine deep green, snow blue shadows, rabbit warm brown accents.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
