# Scene

A hedgehog among fallen leaves, mushrooms and a tiny snail on a forest path.

# Composition

Hedgehog center; leaf piles in three corners; mushrooms mid-left; snail lower-right; path leading back as depth cue.

# Color direction

Warm rust and amber leaves, mushroom coral caps, hedgehog brown spines, soft teal path shadows.

# Special instructions

All subjects should be reassuring and friendly for ages 3–10. Create one unified scene with visible clues in every quadrant, not a collage or a set of stickers. Prefer rich midtones that separate clearly from warm cream and beige board colors.
