# Jigsaw 3D Implementation Plan

> For agentic workers: implementation is a standalone port; integrate into upstream ThreeShell DI as a separate step.

**Goal:** Play the 3×3 toddler jigsaw on a fixed straight-down 3D board.

**Architecture:** Domain is renderer-neutral. Scene owns Three.js objects, input, animations and pipelines. React owns HUD/mount lifecycle.

**Tech Stack:** TypeScript, Three.js, React, Vite, minimal ThreeShell-compatible runtime.

**Spec:** `docs/superpowers/specs/2026-11-21-jigsaw-3d-design.md`

## Tasks

- [x] Domain: seeded complementary edges, piece state machine, snap rules; tests for deterministic generation and valid transitions.
- [x] Geometry: reconstruct segments into Three.Shape, extrude, orient along XZ, map shared texture UVs.
- [x] Scene: board, lighting, orthographic camera, renderer resource ownership.
- [x] Input: raycast selection, horizontal-plane drag, pointer capture and command queue.
- [x] Animation: fixed-step ease, snap/return transition, completion callback.
- [x] UI: progress, restart, completion, responsive layout.
- [ ] Verify browser runtime after installing npm packages in a network-enabled environment.
- [ ] Upstream integration: replace local runtime with actual ThreeShell DI and Next.js auto-discovery.
