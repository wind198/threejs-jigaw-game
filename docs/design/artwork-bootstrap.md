# Artwork bootstrap and status screens
Decode configured artwork before creating texture or meshes in awaited SceneResources.onSceneInit. Only omitted paths produce sample art. Decode timeout: 15 seconds. Cancel on unmount/replay. Failed initialization rolls back all constructed providers, including those with not-yet-run hooks. Preserve native raster/sRGB and unlit material.
Shared illustrated status screens cover dynamic game import, hydration, artwork loading, game errors, route loading/error and not found. Status-specific inline SVGs communicate meaning without reading: assembling puzzle for loading, separated pieces with exclamation mark for errors, missing puzzle piece with magnifier for 404. No animal mascots or external illustration assets in status screens. Large graphics and 40px action icons with 11px labels; no fabricated loading percentage. Reduced motion disables both loading-track and piece-assembly animations. Retry is available on errors, pictures on errors/404. Static host must serve exported 404.html with actual HTTP 404.
