# Artwork bootstrap and status screens
Decode configured artwork before creating texture or meshes in awaited SceneResources.onSceneInit. Only omitted paths produce sample art. Decode timeout: 15 seconds. Cancel on unmount/replay. Failed initialization rolls back all constructed providers, including those with not-yet-run hooks. Preserve native raster/sRGB and unlit material.
Shared illustrated status screens cover dynamic game import, hydration, artwork loading, game errors, route loading/error and not found. Status-specific inline SVGs communicate meaning without reading: assembling puzzle for loading, separated pieces with exclamation mark for errors, missing puzzle piece with magnifier for 404. No animal mascots or external illustration assets in status screens. Large graphics and 40px action icons with 11px labels; no fabricated loading percentage. Reduced motion disables both loading-track and piece-assembly animations. Retry is available on errors, pictures on errors/404. Static host must serve exported 404.html with actual HTTP 404.
QA: slow refresh /play/animals-bamboo-panda-village/, blocked image, retry, navigation during decode, unknown route, short landscape, reduced motion. Run npm run typecheck and npm test. Browser/CI unverified.

Gameplay artwork overlay remains opaque for at least 500ms from initialization. Once the decoded scene starts rendering, wait only the remaining minimum interval, then fade opacity over 280ms before enabling unobstructed gameplay. Errors replace loading immediately. Cancel reveal/fade timers on retry/unmount/failure. Reduced-motion or disabled animation skips the fade but retains the minimum. This timing applies to scene startup/retry; Next.js route and dynamic-import fallbacks are separate.

Reveal is gated on the first successful presentation of populated puzzle geometry to a nonzero-sized canvas, not on application construction or animation-loop registration. Renderer sizing updates the drawing buffer without overwriting CSS dimensions. A 10-second first-frame watchdog shows retry UI rather than revealing a blank stage; failure cancels reveal timers. Browser reproduction and verification remain required.
