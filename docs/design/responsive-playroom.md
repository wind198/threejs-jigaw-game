# Responsive playroom
The board stays in the original six-unit coordinate system; only tray slots, tabletop dimensions and orthographic framing change. Landscape has two side trays. Portrait has a paginated bottom tray. Slot pitch accounts for the piece contour and bevel. Reflow and page changes wait for idle piece states, preserving placed pieces and snap targets. Hidden pieces are excluded from raycasting.
The input operator supports drag and tap-to-place with a six CSS pixel tap threshold, pointer capture and cancellation. A selected piece is lifted visually. Progress, tray navigation, sound, hint and restart controls are outside the canvas. The picture guide consumes separate layout space. Browser confirmation protects in-app exit and restart; browser history navigation and persistence of unfinished games are not covered. Error/retry UI handles bootstrap, artwork and frame failures.
