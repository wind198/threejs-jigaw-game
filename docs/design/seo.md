# Static SEO foundation
Set NEXT_PUBLIC_SITE_URL to the final public HTTPS origin before building. Unconfigured builds deliberately emit noindex, disallow crawling, omit canonical URLs and produce an empty sitemap. CI uses a reserved invalid test domain only; never deploy that output. Build with the real domain, deploy out/ on a host serving directory index.html and genuine 404 responses, redirect alternate hosts and HTTP to HTTPS. Submit /sitemap.xml in Google Search Console, verify DNS ownership, inspect representative URLs and monitor indexing. No tracking scripts.
All existing puzzle URLs stay canonical. Puzzle URLs open the playroom directly, with a static visible title and loading shell while the client game initializes. No detail page or related-puzzles panel. Metadata, canonical URLs, sitemap image entries and crawlable catalog links remain. The primary puzzle image is rendered in WebGL during gameplay rather than as a prerendered img on the play route; image discovery relies on catalog thumbnails, metadata and the image sitemap. This intentionally reduces static descriptive content on play routes. All catalog links are rendered without Show More; images stay lazy. Parent settings remain crawlable but noindex. Sitemap includes artwork URLs. Favicon is original generated artwork resized for browser/search display.
